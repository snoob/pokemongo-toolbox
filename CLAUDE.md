# CLAUDE.md

Guidance for Claude Code when working in this repository.

## What this is

`pokemon-crawler` — a **bare, freshly-scaffolded Symfony 8.1 CLI project** (PHP >= 8.4, running on PHP 8.5 locally). Only the skeleton exists so far; there is no application code yet.

Everything in the repo comes from a single commit (`d3b7b11 Add initial set of files`) generated by Symfony Flex recipes.

## Current state — read before doing anything

The skeleton is **incomplete and does not boot**. `php bin/console` currently throws:

```
Attempted to load class "Kernel" from namespace "App".
```

Missing pieces a normal `symfony/skeleton` install would have:

- `src/` and `tests/` directories (both are declared in `composer.json` autoload but do not exist)
- `src/Kernel.php` — required by `bin/console`, which does `new App\Kernel(...)`
- `config/services.yaml` and `config/packages/framework.yaml`
- `.gitignore`

Consequence: **`vendor/` is committed to git** because there is no `.gitignore`. Any `composer install`/`composer update` will produce a very large diff. Add a proper Symfony `.gitignore` (and `git rm -r --cached vendor`) before touching dependencies, unless the user says otherwise.

So the first task in this repo is almost certainly bootstrapping: create `src/Kernel.php` (the standard `MicroKernelTrait` kernel), `config/services.yaml`, `config/packages/framework.yaml`, then verify `php bin/console` lists commands.

## Stack

- PHP >= 8.4 (local CLI: 8.5), Composer 2.9
- Symfony 8.1 components, pinned via `extra.symfony.require: 8.1.*`
- Only `FrameworkBundle` is registered (`config/bundles.php`)
- Installed: `console`, `dotenv`, `flex`, `framework-bundle`, `runtime`, `yaml`. **No** Doctrine, HttpClient, Messenger, Twig, or test framework — a crawler will need at least `symfony/http-client`, and likely a persistence layer.
- `require-dev` is empty: there is no PHPUnit/Pest, no PHP-CS-Fixer, no PHPStan. Do not assume a test or lint command exists; add the tooling explicitly if the user wants it.

## Commands

```bash
composer install                # install deps (note the vendor/ caveat above)
php bin/console                 # broken until src/Kernel.php exists
php bin/console list            # list commands once the kernel is in place
php bin/console debug:router    # list routes
```

Use `composer require <pkg>` so Flex applies recipes (it writes `config/packages/*` and updates `symfony.lock`); avoid hand-editing `composer.json` for new deps.

## Conventions

- PSR-4: `App\` → `src/`, `App\Tests\` → `tests/`
- Environment config lives in `.env` (committed defaults) and `.env.local` (uncommitted overrides). Never put secrets in `.env`; use `.env.local` or Symfony secrets.
- Routes are attribute-based (`config/routes.yaml` imports `routing.controllers`), though this is a console-oriented project — CLI entry points should be `#[AsCommand]` classes in `src/Command/`.
