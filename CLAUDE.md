# CLAUDE.md

Guidance for Claude Code when working in this repository.

## What this is

`pokemongo-toolbox` — a **Pokémon GO PvP toolbox**: a Symfony 8.1 CLI application
distributed as a PHAR. PHP >= 8.5.

It answers what a player asks before spending resources on a Pokémon: league rank, IV
rank within the species, the spread worth hunting, the recommended moveset, and — for
megas — the CP to stop at before evolving.

**`GUIDELINES.md` is the reference**: conventions, architecture, and a numbered decision
log explaining *why* each choice was made. Read it before writing code; add a row to the
log when you decide something structural, including when you reverse an earlier decision.

## Commands

```bash
bin/console pogo:pvp:rank <pokemon> [ivs]   # the feature
bin/console pogo:data:build                 # refresh game data from upstream (~3 s)

vendor/bin/mago format && vendor/bin/mago lint && vendor/bin/mago analyze && vendor/bin/phpunit
```

The quality chain must pass before every commit. Mago replaces PHP-CS-Fixer and PHPStan;
its analyser runs at maximum severity, and an error gets fixed rather than silenced — see
GUIDELINES §10.

## Shape of the code

DDD in four layers, `UI → Application → Domain` and `Infrastructure → Domain`. The domain
holds the game's formulas and depends on nothing — a `use Symfony\` under `src/Domain/`
is a bug. Every external source sits behind a port with an in-memory fake for tests.

Two data tiers: `data/*.json` and `translations/*.xlf` are generated by `pogo:data:build`
and committed, read at runtime without network; only the league rankings are fetched at
run time, behind a 24-hour cache.

## Things that will surprise you

- **A PHAR is read-only and `glob()` does not work under `phar://`.** Three consequences
  are handled in `src/Kernel.php` and `config/services.yaml`, each documented in place and
  in GUIDELINES §12 (decisions 49 to 52). A `resource:` path ending in `/` registers zero
  services there, silently.
- **The interface is English, the game data follows `--locale`.** Species and move names
  are translated; headers, labels and errors are not.
- **One value in the project comes from no upstream file**: the mega-exclusive move's
  power multiplier, sourced from the community wiki and isolated in
  `MegaLevelTableBuilder` with its provenance.
